## About Me

I am a Data Science student at Saigon University in Ho Chi Minh City, Vietnam, focusing on **applied AI with Python**.

I build practical tools that put AI to work on real business problems: chatbots that answer from a company's own documents, image models fine-tuned for a specific task, and automated pipelines that collect, analyse and report data every day.

- 🎓 Studying Data Science at Saigon University, currently taking Deep Learning
- 🤖 Building LLM applications: RAG, structured outputs, API integration
- 👁️ Training and evaluating computer vision models with PyTorch
- ⚙️ Automating repetitive workflows with Python, LLMs and scheduled jobs
- 🤝 Open to small, clearly scoped AI integration and automation projects
